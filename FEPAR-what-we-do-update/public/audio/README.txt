FEPAR Theme Songs

Save approved MP3 files in this folder using these exact names:

- fepar-theme-song.mp3 — FEPAR Theme Song
- festac-at-50-anthem.mp3 — FESTAC at 50 Anthem
- pan-african-renaissance.mp3 — Pan-African Renaissance

The website checks for these filenames and automatically lists each file it finds on /theme-songs/. You do not need to edit the code to add one of these tracks. Add the MP3s to `public/audio/` in the project, rebuild and redeploy the site.

Keep artist, songwriter, performer and rights information with each track. Only publish music cleared for website playback. The page supports standard browser controls and optional user-started looping background playback.
