## ❓ Troubleshooting

### Can't see the site?
Check firewall settings allow port 3002

### Site shows blank/white?
Open browser DevTools (F12), check console errors

### Need to stop server?
Press `Ctrl+C` in terminal where `npm run dev` is running

### Want production build?
Run `npm run build` then `npm run preview`
